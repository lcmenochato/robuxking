KINGDOM ROBUX — FLEVO PAY

Conteúdo:
- index.html — site Kingdom Robux com checkout PIX e fluxo de confirmação/upsell.
- upsell.html — página/artefato do upsell em identidade amarelo + preto.
- api/worker.js — Cloudflare Worker da integração FlevoPay/TikTok.
- api/submit.php — backend original de captura de leads, preservado.
- css/ — estilos originais do Kingdom.
- js/ — scripts originais.
- images/ — imagens originais do Kingdom, preservadas.

IMPORTANTE:
O api/worker.js é o código para publicar como Cloudflare Worker. As variáveis/secrets da FlevoPay e TikTok devem ser configuradas no Cloudflare conforme o código.
